# .github

Organization-level files for [Apich Organization](https://github.com/Apich-Organization).

| Path | What it is |
| --- | --- |
| `profile/README.md` | The profile rendered on the organization page, plus the logo files it references. |

The website lives in [main-website](https://github.com/Apich-Organization/main-website)
and is served at [apich.org](https://apich.org/). That repository also generates
`sitemap.xml`, `robots.txt`, `llms.txt` and the structured data for every page —
nothing site-related belongs here any more.

Properties that keep their own subdomain (`tou`, `ygs-2026`, `ncee`, `status`
and the personal sites) are listed in the site's sitemap and are not routes of
the main site.
